# Marcas y proyectos activos

Cada archivo en este directorio define el DNA de una marca/proyecto: voz, estilo visual, tools, audiencia y reglas no-negociables.

**Antes de generar contenido creativo (script, brief, concept, art-direction, generate, storyboard, etc.) leer el archivo de la marca correspondiente.** Si el usuario no aclara para qué marca es, preguntar.

Status posibles:
- `active` — en producción ahora
- `new` — recién arrancando, DNA sin completar
- `paused` — sin actividad reciente
- `lead` — todavía no es cliente

## Plantilla

Cada archivo de marca sigue esta estructura:

```markdown
# <Nombre>

## Meta
- Industria, idioma, plataformas target, status, relación con otras marcas

## 1. Voice
- Tono, vocabulario, referentes, prohibiciones

## 2. Visual style
- Paleta, lighting, composición, referencias

## 3. Tools
- Generación, edición, otras

## 4. Audience
- Demografía, intereses, nivel de expertise

## 5. Rules (no-negociables)
- Lo que JAMÁS se hace para esta marca
```

Las secciones marcadas como `_TBD_` están pendientes de definir.
